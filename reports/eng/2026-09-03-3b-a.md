## 구현 노트

- **크기 산정은 닫힌 식** (brief-3A §8 정정): `σ = We/4.133`, `W*_1d = 4.1075·σ`.
  a·b·A_c 는 W\* 에 안 들어간다 — 예측 이동시간만 별도 표시 값(`predMT(W)`).
  `W*_2d = 2.537·σ` 는 "왜?" 정직성 수치(표시 전용).
- **Φ⁻¹ 는 자체 구현** (Acklam) — `npm` 런타임 의존성 0 유지. 절대오차 ~1.15e-9,
  브리프 요구치 1e-4 를 크게 밑돈다. `Φ⁻¹(0.98)=2.05375` 상수 테스트.
- **보정값은 CSS px per mm** (device px 아님) — 주석·타입·문서에 명시. 조건 기하는
  건드리지 않았다 (brief-3A §8 C3). `s2-measure.ts` 의 `calibrated:false` 스텁은
  범위 밖이라 그대로 뒀다 — 아래 "project-lead 에게" 참조.
- **dpr 불일치**는 상대오차(`|Δ|/dpr > 0.05`)로 판정 — 정확 일치는 브라우저 줌마다 뜸.
- **보정 권유**는 S1(측정 준비 = "첫 측정 직전")에 인라인 배너로. 저장/스킵/보정 진입
  어느 쪽이든 `calibrationPrompted=true` → 재권유 없음.
- 상수는 전부 `src/adapt/sizing.ts` 에 이름 있는 상수 (하드코딩·매직넘버 없음).
- 프리셋 `labelKey` 3개(`adapt.preset.*`)는 3B-b UI 가 쓸 키지만 지금 i18n 에 채워 뒀다
  (브리프가 `labelKey: string // i18n 키` 로 명시).
